# AniView - 动漫桌面客户端

基于 Electron + Bangumi API + HLS.js 的 Windows 动漫桌面应用。

## 功能

- **搜索** - 支持中文/日文/罗马音搜索，别名匹配
- **分类浏览** - 按年份、动画形式、评分/热门筛选，每页 20 条，可加载更多
- **每日放送** - 查看当季放映表
- **视频播放** - 内置 HLS 播放器，倍速、全屏、选集
- **收藏管理** - 收藏喜欢的动漫
- **观看历史** - 自动记录播放进度，跨集续播
- **线路切换** - 按源站实际剧集目录发现线路，播放失败时可切换
- **快速加载** - 首页分区独立显示，目录缓存持久化，播放地址按需解析

## 快速开始

### 本地便携版（免安装）

仓库只提供源码，不上传本地 `dist` 产物。如已在本地构建，解压 `dist/AniView.zip` 后运行 `AniView.exe`，或直接双击 `dist/AniView/AniView.exe`。
更新后需先退出已打开的旧版窗口，再重新启动。收藏和观看历史仍保存在原来的用户数据目录。

### 开发模式

```bash
# 安装依赖
npm ci

# 启动
npm start
```

安装时会自动生成 HLS.js 播放资源并复制其上游许可证；这些生成文件不纳入 Git。应用的收藏、观看记录和目录缓存保存在用户数据目录，不随源码上传。

### 打包

```bash
# 生成安装包 + zip
npm run build

# 仅生成便携版 exe
npm run build:portable
```

## 技术栈

- **Electron** - 桌面框架
- **原生 JavaScript** - 前端渲染
- **HLS.js** - 视频流播放
- **Bangumi API** - 动漫元数据
- **cheerio + node-fetch** - 视频源解析
- **本地 JSON 存储** - 收藏、历史与独立的目录缓存

## 验证与故障排查

桌面程序的目录与播放源请求统一使用 Electron 系统网络层，自动跟随 Windows 的代理/PAC设置，不依赖启动终端中的 HTTP_PROXY 环境变量。无需把代理地址写死在启动脚本里。

运行 `npm test` 执行无需联网的回归测试。`tests/electron-smoke.cjs` 是需联网的 Electron 集成测试，使用 `.repair-verification/user-data` 隔离测试记录，不修改个人收藏或历史。

运行 `node scripts/verify-desktop-network.js` 可执行“清空代理环境变量 + 全新缓存目录”的桌面联网验证，加 `--packaged` 验证本地构建的 ASAR。此方式用于排除开发终端环境和旧缓存造成的假通过。错误诊断写入用户数据目录的 `network-errors.log`，仅包含请求主机和错误代码，不含搜索内容或代理凭证。

目录请求超时后可在对应区域点击“重新加载”。目录缓存新鲜期为 30 分钟，七天内的旧缓存会立即显示并在后台更新；失败请求不会被保存成空列表。播放来源并行查询，整体最多等待 15 秒，首个验证成功的线路立即播放；视频启动另有独立超时和跨来源切换。

动漫资料来自 Bangumi，是否有视频取决于现有第三方源站是否收录以及线路当前是否可用。“源站已收录”表示目录中有该集，不保证每条线路均可播放。源站网络失败不会隐藏动漫资料。

真实窗口布局验证脚本为 `tests/electron-layout.cjs`，联网播放验证脚本为 `tests/electron-source-smoke.cjs`。测试报告、截图、备份和用户数据均不会提交到仓库。
